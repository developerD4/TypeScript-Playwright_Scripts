Key takeaways:
Call Stack executes synchronous code.
Web APIs handle asynchronous operations like timers, network requests, and events.
Completed Promise callbacks (.then(), .catch(), .finally()) go to the Microtask Queue.
Completed timer and event callbacks (setTimeout, onclick, I/O callbacks) go to the Macrotask Queue.
The Event Loop waits until the Call Stack is empty, then executes all microtasks before taking the next macrotask. This priority is why Promise callbacks run before setTimeout(..., 0) callbacks.
